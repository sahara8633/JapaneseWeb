# JapaneseWeb

히라가나·가타카나와 JLPT 단어를 매일 연습하는 퀴즈 웹페이지예요.

**글자 탭**
- 히라가나 / 가타카나 / 섞어서 중 골라서 출제 (섞어서는 두 글자 모두 나와서 전체 수가 2배)
- 답하는 방법: 보기 고르기, 발음 쓰기(한글로 입력), 글자 쓰기(손으로 쓰면 정답 글자와 모양 일치율을 계산해서 자동 채점. 70% 이상이고 다른 글자와 더 닮지 않았으면 정답. 채점이 틀리면 '채점 바꾸기'로 고칠 수 있어요. 계산은 `match.js`)
- 글자 쓰기에서 소리가 같은 글자(お·を, じ·ぢ, ず·づ)는 한 번만 묻고 둘 다 정답으로 쳐요
- 보기의 오답은 모양이 비슷한 글자나 소리가 비슷한 발음 중에서 매번 다르게 골라요
- 범위: 기본 46자, 탁점·반탁점, 작은 ゃゅょ
- 문제 수: 10, 20, 30, 전체(고른 범위의 글자 수) 또는 직접 입력. 한 바퀴를 다 돌기 전에는 같은 문제가 다시 나오지 않아요
- 기다리는 동안 카드의 글자가 몇 초마다 바뀌어요

**단어 탭**
- JLPT N5~N1 급수별 필수 단어 각 100개 정도 (`words.js`)
- 단어 보고 뜻 고르기, 뜻 보고 단어 고르기. 오답은 같은 품사나 같은 한자가 들어간 단어 중에서 골라요
- 한자 위 히라가나(후리가나) 보이기/숨기기 (외우기 탭과 같은 설정)

**쓰기 탭 (채점 없는 연습)**
- 위에서 히라가나·가타카나(탁점, 작은 ゃゅょ 포함)를 고르면, 왼쪽 카드에서 획순을 한 획씩 그려 보여 줘요. 다시 보기, 한 획씩 앞뒤로 넘기기
- 오른쪽 큰 칸에 획순 가이드를 보면서 따라 써 볼 수 있어요 (가이드 켜기/끄기, ←/→로 글자 이동, 처음과 끝에서 멈춤)
- 인쇄체 모양도 같이 보여 줘요. 획순은 손글씨 모양이라 획 끝(삐침 등)이 인쇄체와 조금 다를 수 있어요

**외우기 탭**
- 급수, 단어 수(10/20/30/전체/직접), 앞면(단어 먼저/뜻 먼저), 후리가나를 고르고 시작해요
- 카드로 외우기: '뜻 보기'(Space)로 뒤집고 몰라요(1)/알아요(2). 몰라요 한 단어는 몇 장 뒤에 다시 나와서, 다 알 때까지 반복해요. ←/→(또는 이전·다음 카드 버튼)로 지나간 카드를 다시 볼 수 있고, 이번에 본 첫 카드에서 멈춰요. 끝나면 헷갈렸던 단어를 보여 주고 그것만 다시 할 수 있어요
- 써 보며 외우기: 단어의 읽기와 뜻을 위에 보여 주고, 한자(와 가나)를 한 글자씩 획순대로 보고 큰 칸에 따라 써요. 채점 없음
- 익힌 단어 수가 저장돼요 (로그인하면 계정에도)

획순 데이터: [KanjiVG](https://kanjivg.tagaini.net) (© Ulrich Apel, CC BY-SA 3.0) → 가나 `kana-strokes.js`, 급수별 한자 `strokes/N5.json` ~ `N1.json`

**공통**
- 틀린 것만 다시 풀기, 연속 일수
- '기록' 탭: 이번 주 기록, 자주 틀린 글자·단어, 기록 옮기기
- 테마: 라이트 / 다크 / 라이트다크(위쪽만 어둡게). 처음엔 기기 설정을 따라가요
- 기록은 브라우저(localStorage)에 저장되고, Google로 로그인하면 계정에도 저장돼서 다른 브라우저나 기기에서 이어서 볼 수 있어요. 로그인 없이 '기록 옮기기'로 옮길 수도 있어요.

## 실행

빌드가 필요 없는 정적 페이지예요. `index.html`을 브라우저로 열면 바로 돼요.
(로그인 기능은 파일로 열면 동작하지 않아요. GitHub Pages 같은 웹 주소로 열어야 해요.)

## 파일 구성

- `index.html`: 페이지 구조(HTML)
- `style.css`: 스타일
- `script.js`: 퀴즈 동작, 기록 저장, 테마
- `match.js`: 글자 쓰기 모양 일치율 계산
- `words.js`: JLPT 급수별 단어 데이터 (단어|읽기|뜻|품사)
- `kana-strokes.js`: 가나 획순 데이터 (KanjiVG, CC BY-SA 3.0)
- `strokes/N5.json` ~ `N1.json`: 급수별 단어에 나오는 한자 획순 데이터 (KanjiVG). 써 보며 외우기를 시작할 때 그 급수 파일만 불러와요
- `sync.js`: Google 로그인과 계정 기록 동기화 (Firebase)
- `firebase-config.js`: Firebase 웹 앱 설정값

## 호스팅

폴더의 파일을 모두 같은 위치에 올리면 돼요. 정적 사이트를 받는 곳이면 어디든 쓸 수 있어요.

- **GitHub Pages**: 저장소 Settings → Pages → Branch를 `main` / `(root)`로 설정
  (비공개 저장소에서 Pages를 쓰려면 유료 플랜이 필요해요. 무료로 쓰려면 저장소를 공개로 바꾸세요.)
- **Netlify / Vercel / Cloudflare Pages**: 이 저장소를 연결하고, 빌드 명령은 비워 두고, 배포 폴더는 `/`(루트)로 설정

폰트는 Google Fonts(Noto Sans JP, Noto Sans KR)에서 불러와요. 인터넷이 안 되면 컴퓨터에 설치된 일본어 기본 폰트로 표시돼요.

## 로그인 설정 (Firebase, 무료)

`firebase-config.js`가 비어 있으면 로그인 버튼이 숨겨지고, 기록은 브라우저에만 저장돼요. 로그인을 켜려면 한 번만 아래처럼 설정하세요.

1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 돼요)
2. **Authentication** → 시작하기 → 로그인 방법에서 **Google** 사용 설정
3. **Authentication** → 설정 → **승인된 도메인**에 `sahara8633.github.io` 추가
4. **Firestore Database** → 데이터베이스 만들기 (프로덕션 모드, 위치는 `asia-northeast3` 서울 추천)
5. Firestore → **규칙** 탭에 아래 규칙을 붙여 넣고 게시

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

6. 프로젝트 설정(톱니바퀴) → 일반 → 내 앱에서 **웹 앱(</>) 추가** → 나오는 `firebaseConfig`의 `apiKey`, `authDomain`, `projectId`, `appId`를 `firebase-config.js`에 붙여 넣기

`apiKey` 같은 웹 설정값은 공개돼도 괜찮아요. 각자 자기 기록만 읽고 쓸 수 있게 막는 건 5번의 보안 규칙이에요.
